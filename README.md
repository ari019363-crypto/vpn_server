# 🔐 VPN Manager Bot

یک ربات تلگرام کامل برای مدیریت سرور WireGuard VPN

## 🚀 قابلیت‌ها

- ساخت کاربر جدید با حجم و زمان مشخص
- تولید کانفیگ WireGuard
- مدیریت حجم و زمان کاربران
- آمار و وضعیت سرور
- کنترل کامل از طریق تلگرام

## 📦 نصب

1. ریپازیتوری را کلون کنید
2. فایل `.env` را تنظیم کنید
3. در Railway یا هر سرور دیگری دیپلوی کنید

## 🛠️ تنظیمات

متغیرهای محیطی:

- `BOT_TOKEN` — توکن ربات تلگرام
- `OWNER_ID` — آیدی عددی مالک
- `PUBLIC_IP` — آدرس عمومی سرور
- `WG_PORT` — پورت WireGuard

## 📱 استفاده

1. ربات را استارت کنید
2. از منو کاربر جدید بسازید
3. کانفیگ را دریافت کنید
4. در اپلیکیشن WireGuard وارد کنید
